# 2608.03020: LoCA, Forward-Only LLM Tuning after One-Shot Calibration with Local Credit Assignment

## 2. Summary

LoCA is a two-stage, mostly backprop-free method for *fine-tuning* a frozen pretrained transformer
with low-rank residual adapters.

- **Stage I (calibration):** one probe backward pass collects, for each block, the exact hidden-state
  gradients `g_l` and the top-layer error `e`. A ridge regression then fits a linear "feedback
  operator" `F_l` (d x d, truncated to rank 8) that predicts `g_l` from `e`. The top-layer error
  `e = W_u^T(softmax(z) - onehot(y))` is computable in closed form from a forward pass.
- **Stage II (forward-only tuning):** every outer iteration runs one forward pass, computes `e`
  analytically, and forms a per-block hidden-state target `tau_l = h_l - eta_bar F_l e`. Each block's
  adapter `B_l` is fitted to that target with a closed-form ridge solve, using streaming sufficient
  statistics `G_l = sum p p^T` (r x r) and `C_l = sum rho p^T` (d x r).

There is no learning rate, no optimizer state, and no backbone backward pass after calibration. The
calibrated feedback has cosine 0.3-0.5 with the true hidden-state gradient, against -0.005 for random
(DFA-style) feedback. LoCA needs at most 40 outer iterations, against 10^3-10^4 steps for
adapter-MeZO, and it matches or beats LoRA cross-entropy in 16 of 25 Qwen2.5 (0.5B-14B) task/scale
cells. The scope is explicitly *small-shift* adaptation; pretraining is not tested.

## 3. Algorithm

**Notation:**

- `L` frozen blocks; width `d`; vocab `V`; frozen head `W_u in R^{V x d}`; logits `z = W_u h_L`.
- `h_bar_l = f_l^base(h_{l-1})` is the frozen block output.
- `A_l in R^{r x d}` is a *fixed random* projection (distribution not specified); `B_l in R^{d x r}` is fitted.
- Rank `r = 32`.

**Adapted forward (Eq. 1/14):** `h_l = h_bar_l + B_l A_l h_{l-1}`. Define `p_l = A_l h_{l-1}`
(in `R^r`). With `B = 0`, this is the frozen model.

**Top-layer error per position t (Lemma C.1):** `e_t = w_t W_u^T (softmax(z_t) - onehot(y_t))`, where
`w_t` is the loss weight (0 for masked positions). Note: this treats `h_L` as directly feeding
`W_u`, ignoring any final norm (see caveats).

**Stage I, one-shot calibration (Eq. 5, 40-47):**

1. Run one forward and backward pass on a probe set. Take `N_p` probe positions (size unspecified).
   Stack `E~ = [e^(1..N_p)]` and `G~_l = [g_l^(1..N_p)]`, both `d x N_p`. Here
   `g_l = dL/dh_l` is the exact gradient, including cross-token terms from attention.
2. Ridge fit: `F_hat_l = G~_l E~^T (E~ E~^T + beta I_d)^{-1}`, computed with a linear solve, not an
   explicit inverse. `beta > 0`; the value is unspecified.
3. Truncate by SVD: `F_hat_l = U Sigma V^T`, then `F_l = U_k Sigma_k V_k^T` with `k = 8`. Store
   `U_k Sigma_k` (d x 8) and `V_k` (d x 8). Apply as `F_l e = U_k(Sigma_k(V_k^T e))`.

**Stage II, outer iteration t (Algorithm in S8 / Section M), Jacobi schedule:**

1. Forward the adapted model on a batch. Cache `h_{l-1}`, `h_bar_l`, `p_l = A_l h_{l-1}` for each block, and `e` at each prediction position.
2. For each block: compute `q_l = F_l e` per position.
3. Compute the scale-normalized step per block and mini-batch (Eq. 10/68), where
   `RMS(X) = ||X||_F/sqrt(numel)`:
   `eta_bar_l = eta * RMS(H_{l-1}) / RMS(Q_l)`, or 0 if `Q_l = 0`.
   Then `RMS(eta_bar_l Q_l) = eta * RMS(H_{l-1})`, so `eta` is a *relative* change of the residual stream.
4. Residual target (Eq. 6/50): `rho_l = B_l^(t) p_l - eta_bar_l q_l`. This equals
   `tau_l - h_bar_l` with `tau_l = h_l - eta_bar_l F_l e`.
5. Accumulate over mini-batches and N selected prediction positions (Eq. 62-65):
   `G_l += sum p p^T` (r x r) and `C_l += sum rho p^T` (d x r). Optional per-position weights `a_n`.
6. Closed-form ridge update (Eq. 8/66): solve `(G_l + lambda I_r) X = C_l^T`, then
   `B_l^(t+1) = X^T`. `lambda > 0`; the value is unspecified (selected).
7. Evaluate held-out CE. Keep the best snapshot. The frozen model (`B = 0`) is always a candidate.
   Stop at T <= 40 or on early stopping.

A Gauss-Seidel variant updates block l, then re-forwards downstream blocks before solving l+1.
Which schedule the experiments used is not stated.

**Hyperparameters (reported):**

- `r = 32`, `k = 8`, at most 40 outer iterations, early stopping on held-out CE.
- `eta in {0.003, 0.01, 0.03}` (relative), selected by held-out CE, with the same candidate set at all
  scales.
- `beta`, `lambda`, probe size, number of fitted positions N, and the distribution of `A_l` are not
  given.
- Seed 0, single runs; NVIDIA L40S or 32 GB CPU-only servers.
- MeZO baseline: LR scaled by `1/sqrt(D)` and searched per scale.

**Why it should work (Prop. D.1):**

- If `<G_l, Q_l> >= gamma ||Q_l||^2`, then a virtual hidden-state step `-s Q_l` decreases the loss
  for `0 < s < 2gamma/M_l`.
- Corollary D.2: with relative feedback error `epsilon < 1`, descent holds for
  `s < 2(1-epsilon)/(M(1+epsilon)^2)`.
- There is no monotonic-descent guarantee for the outer loop.

**Costs per outer iteration and block (Section K):**

- `P = A H`: O(N d r). `F e`: O(N d k). `G`: O(N r^2). `C`: O(N d r). Solve: O(r^3 + d r^2).
- Persistent state: O(L(r^2 + dr + dk)), independent of the number of tokens processed.

  0.93-1.29.

**Feedback alignment:** random `F` gives mean cosine -0.005. The calibrated rank-8 `F` gives 0.3-0.5,
in-probe only.

## 5. Classification for Crowd v1.5

**Complement to DUST,** not a replacement. LoCA is a fine-tuning method on a frozen backbone and
assumes small representation shift. In pretraining, the backbone moves far from any calibration
point.

**DUST shortcoming addressed: low gradient cosine and high variance** of per-layer output-gradient
estimates, and with it the **compute cost per useful step.**

- DUST already estimates `dL/dy_l` for each perturbed linear output and forms weight gradients as
  outer products with inputs. LoCA's key observation is that `dL/dh_l ~= F_l e`, a cheap,
  deterministic predictor of exactly that quantity, computed from the analytically known top error,
  with cosine 0.3-0.5. That is far above typical DUST per-layer cosines at affordable populations.
- **Ideas to test:**
  - (a) Use `F_l e` as a *control variate or prior mean*. DUST then estimates only the residual
    `g_l - F_l e`, or perturbations are drawn in a subspace biased toward `F_l e`.
  - (b) Use `F_l e` directly as a feedback-alignment-style gradient between recalibrations.
  - (c) Fit `F_l` *from DUST's own noisy estimates* instead of a backprop probe. Ridge regression of
    zero-mean-noise targets on `e` is unbiased in expectation, so no client needs backward support.
    This is our idea, not the paper's.
- **Communication bytes (secondary):** the ridge sufficient statistics `G_l` (r x r) and `C_l`
  (d x r) are *additive across clients*. A worker could upload `r^2 + dr` floats per block, and the
  coordinator would sum them and solve. That is a natural fit for crowd aggregation, but it applies
  only to the adapter subspace.
- **Memory (secondary):** the forward-only stage has inference-level memory.
- **Does not address:** Byzantine peers (additive statistics are easy to poison, so they would need
  robust aggregation), stragglers, or sigma instability.

## 6. MVP recipe (2-10 min, M5 Max, MPS)

Use `research/lab/harness.py` on preset `10m` (6 layers, d=256, vocab 4096, seq 128, tied
embeddings, `norm_f` before the head). Two experiments, A cheapest first:

**A. Does calibrated feedback predict pretraining gradients, and for how long? (~3 min)**

1. Train Adam-BP for about 60 s to get a non-random checkpoint θ0.
2. **Calibrate.** On 16 batches (B=8, T=128, so N_p is about 16k positions):
   - Record `e = W_u^T(softmax - onehot)`, taken w.r.t. the `norm_f` *output*.
   - Record exact `g_l = dL/dh_l` at each block output, plus at the DUST-perturbed linear outputs
     (`attn.o`, `mlp.down`) via hooks with `retain_grad`.
   - Ridge-fit `F_l` (256 x 256): `F = G E^T (E E^T + beta I)^-1` with `beta = 1e-3 * tr(E E^T)/d`.
   - Truncate to k = 8.
3. Continue Adam training. Every 50 steps, measure the cosine between `F_l e` and the true `g_l`, per
   layer, per token, and aggregated over the batch.
4. **Baselines on the same batch:**
   - The cosine of a DUST per-layer estimate with the true gradient (`crowd_v15.dust.probe_cosine`)
     at pop in {16, 64}.
   - The cosine of random feedback.
   - The cosine of `F_l` fitted from *DUST estimates* in place of exact `g_l` (idea c).
5. **Proves out if:**
   - The in-probe cosine is at least 0.3 (reproducing the paper).
   - It stays at least 0.2 for 200 or more Adam steps.
   - It exceeds DUST's per-layer cosine at pop=64.
   - The DUST-fitted `F_l` reaches at least half the cosine of the exact-fitted one.

**B. Faithful LoCA (adapter fine-tuning under a small shift) vs LoRA vs adapter-MeZO vs DUST-on-adapter (~5 min)**

1. **Base and shift.** Freeze the A.1 checkpoint (or a 5-minute Adam model). The "task" is a small
   shift: a held-out FineWeb-Edu slice filtered to one topic, or simply continued LM on fresh tokens.
2. **LoCA:**
   - Adapters `h_l = h_bar_l + B_l A_l h_{l-1}` on each of the 6 blocks, with `r = 32`.
   - `A_l ~ N(0, 1/d)` fixed. This distribution is our choice; the paper does not specify one.
   - One calibration probe, then T <= 40 Jacobi iterations over N = 8 batches each.
   - Relative `eta in {0.003, 0.01, 0.03}`, `lambda in {1e-3, 1e-1} * tr(G)/r`.
   - Snapshot selection by validation CE.
3. **LoRA-equivalent:** the same adapter, `B` trained by Adam with backprop.
4. **Adapter-MeZO:** a two-point estimate on the `B` parameters, `mu = 1e-3`.
5. **DUST** restricted to adapter outputs.
6. **Metrics:**
   - Validation CE vs tokens, vs wall time, and vs forward-equivalents (from the harness `Cost`
     fields: count the calibration backward as 2 fwd).
   - Number of outer iterations needed.
7. **Proves out if:** LoCA recovers at least 0.8 of the LoRA CE gain within 40 iterations, and beats
   adapter-MeZO and DUST-adapter at an equal forward-pass budget.

**Optional C (pretraining extension).**

- Train the full model with `ΔW_l = -lr * (F_l e) ⊗ x_l`, a calibrated-DFA update.
- Recalibrate `F_l` every K steps (K in {50, 200}), using either a backprop probe or DUST estimates.
- Compare loss vs tokens with DUST and Adam.
- This is the real test of whether the idea scales beyond fine-tuning. The paper predicts that
  alignment degrades as the model moves.

## 7. Caveats and unclear points

- **Scope is small-shift fine-tuning of discriminative tasks** on a frozen backbone. No pretraining,
  no generation, no training of backbone weights. Our setting violates the core assumption.
- **The feedback map is a tokenwise, input-independent linear map.** True credit `g_{l,s}` sums over
  later positions (Eq. 24), and the map ignores this. A cosine of 0.3-0.5 is *in-probe*; held-out and
  over-time alignment are not reported.
- **Missing values:** `beta` (feedback ridge), `lambda` (adapter ridge), probe size, the
  distribution of `A_l`, N per iteration, and whether Jacobi or Gauss-Seidel was used. The Stage I
  calibration time was not recorded, so end-to-end speed claims are limited.
- **Final norm ignored.** `e` is defined with `z = W_u h_L`. Real models, Qwen and ours, have a final
  RMSNorm, so `e` must be taken w.r.t. the norm output, or the norm Jacobian must be folded in. The
  paper is silent on this.
- **The adapter is a direct residual-stream correction** `B A h_{l-1}` added to the block *output*,
  not LoRA on weight matrices. It is closer to a parallel adapter.
- **The evidence is weak:** single seeds, descriptive counts, and recovery ratios that are unstable
  when the LoRA gain is small. There is a citation placeholder "[? ]" in the text. The code link was
  not included in the extracted text.
- **Global CE is non-monotone across outer iterations.** Held-out selection, with the frozen model as
  a fallback, is part of the method. That needs a validation set on the coordinator.
- **Adapter-MeZO uses the least memory** in their table. LoCA's advantage is iteration count, not
  memory against ZO.
