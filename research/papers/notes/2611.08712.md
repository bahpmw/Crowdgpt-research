# 2611.08712 — SZO-κ: Spectral Zeroth-Order Perturbations

## 1. Citation
- **Title:** An Educated Guess: Deriving Statistically Aligned Gradient Estimates for Zeroth-Order Optimisation
- **Authors:** Justus Hübotter, Serge Thill, Marcel van Gerven, Nasir Ahmad (Donders Institute, Radboud University)
- **Date:** 5 Nov 2026 (v1), arXiv:2611.08712 [cs.LG]
- **Code:** github.com/EfficientNeuralSystems/spectral-zeroth-order (we did not check it)

## 2. Summary
Random ZO directions are almost orthogonal to the true gradient when the parameter count is high. For a layer
H = W A, the gradient is G = V Aᵀ (V = ∂L/∂H), so its input-side geometry is set by the batch activations A,
which the forward pass already provides. The paper assumes the downstream error V is isotropic. Under that
assumption, the expected squared loss response to a weight probe Ψ is ∝ Tr(Ψ C Ψᵀ) with C = A Aᵀ, which gives
**SZO-κ**: Ψ ∝ R C^{κ/2} with random R. Setting κ=0 gives weight perturbation (WP/SPSA). κ=1 gives a
"matched filter", and NTWP ("node-through-weight perturbation") equals it in expectation. κ→∞ gives a rank-1
probe along C's top eigenvector. In a fully connected layer with per-sample credit, every κ>0 equals node
perturbation (NP). On shared-weight (conv) layers, NP aligns poorly; SZO-1 and NTWP align much better and train
better. An optional activation-awareness weight w = ρ'(h)² cuts variance further. The scope is small: an MLP on
Fashion-MNIST and a 6-layer CNN on CIFAR-10. There are no LLM or transformer results.

## 3. Algorithm

### Notation
- Layer: W ∈ R^{k×q}. Batch inputs A = [a_1..a_B] ∈ R^{q×B}. For conv layers, the columns are receptive-field
  patches; **for a GPT, read the columns as tokens**. H = W A, C = A Aᵀ ∈ R^{q×q} (uncentred second moment).
- G = ∇_W L_B = V Aᵀ with V = ∇_H L_B (used only in the analysis).
- ϵ is the finite-difference scale. σ² is the per-coordinate probe variance (they set σ=1). n is probes per step.
- Probe = one perturbed forward pass plus its scalar loss. Everything is **one-sided**: one clean baseline L0
  plus n perturbed passes.

### Generic one-sided estimator (WP/SPSA, κ=0)
ĝ_n = 1/(n σ² ϵ) Σ_i [L(θ+ϵψ_i) − L(θ)] ψ_iᵀ. Its MSE is ((m + μ4 − 2)/n)·‖g‖² + O(ϵ²), where m is the
parameter count and μ4 = 3 for Gaussian probes (the "curse of dimensionality").

### Node perturbation (what DUST is, roughly)
Perturb h → h + ϵφ, then ∇̂_W L = 1/(nσ_φ² ϵ) Σ_i ΔL_i φ_i aᵀ. The variance scales with k (activations), not with k·q.

### SZO-κ probe (Alg. 1, one layer)
```
clean pass: H = W A, C = A Aᵀ, L0 = L_B(W)
Ĝ = 0
for i in 1..n:
    R_i ~ iid N(0, 1/k), shape k×q          # E[RᵀR] = I_q
    Ψ_i = sqrt(c / Tr(C^κ)) · R_i C^{κ/2}   # E‖Ψ‖_F² = c
    L_i = L_B(W + ϵ Ψ_i)
    Ĝ += (L_i − L0) Ψ_i / (n ϵ c)
return Ĝ          # E[Ĝ] ∝ G C^κ / Tr(C^κ)  (intentional spectral bias)
```
- c is the budget. Per draw you may replace c with the realised ‖Ψ_i‖_F². Two-sided (SPSA-style) use is also allowed.
- Bias = G (C^κ/Tr C^κ − I). Effective dimension is q_eff(κ) = Tr(C^κ)²/Tr(C^{2κ}), and relative variance is
  about k·q_eff/n (an exact 1/n law was measured). Kantorovich worst-case alignment:
  cos(G, G C^κ) ≥ 2√τ/(1+τ), with τ = cond(C)^κ.

### Implementations that avoid eigendecomposition (App. I) — what they actually ran
- **SZO-1, per-sample credit (main training method).** For sample b, stack its L patches/tokens as rows of
  P_b ∈ R^{L×d} (P_bᵀP_b = C_b). Draw G_b ∈ R^{k×L} with iid N(0,1/k). Then **Ψ_b = G_b P_b / ‖P_b‖_F**, which
  has the same distribution as R C_b^{1/2}/√Tr C_b, so no matrix root is needed. For a linear layer (L=1) this is
  NP with a per-sample rank-1 probe. The induced output never needs Ψ_b materialised:
  Ψ_b x_t = G_b (P_b x_t)/‖P_b‖_F, i.e. ΔH_b = (P_b P_bᵀ) G_bᵀ / ‖P_b‖_F (an L×L Gram matrix).
  Update: Ĝ ∝ Σ_b (ΔL_b/ϵ) Ψ_b, using each sample's own loss difference ΔL_b = L_b(W+ϵΨ_b) − L_b(W).
- **SZO-∞, per-sample.** Linear layer: â_b = a_b/‖a_b‖, ΔW_b = φ_b â_bᵀ with φ_b ~ N(0,I_k) drawn per (probe,
  sample); induced Δh = φ_b⟨â_b, a⟩. Conv: â_b = normalised energy-weighted mean patch
  ā_b = Σ_ℓ ‖x_ℓ‖² x_ℓ / Σ_ℓ ‖x_ℓ‖², which approximates C_b's top eigenvector.
- **SZO-2:** R C = (R A) Aᵀ, with normaliser Tr(C²) = ‖AᵀA‖_F². This is two matmuls and needs no root.
- **Newton–Schulz C^{1/2}:** 3 iterations cost about 1% alignment (0.8917 vs 0.9012). 5 iterations match an
  exact eigendecomposition.

### NTWP (Alg. 2) — the cheapest realisable SZO-1
```
for i in 1..n:
    R_i ~ isotropic, k×q            # plain weight noise, no shaping
    L_i = L_B(W + ϵ R_i)
    ΔH_i = R_i A                    # induced activity perturbation (computable locally)
    E_i  = ΔH_i Aᵀ = R_i C          # activity-derived eligibility
    c_i  = ‖ΔH_i‖_F²
    Ĝ += (L_i − L0) E_i / (n ϵ c_i)
```
- With per-batch credit, E[Ĝ] ∝ G C, the same geometry as SZO-1.
- **Per-sample NTWP** (used in all their NTWP training): v_b = R a_b, and
  Ĝ = (1/B) Σ_b k (ΔL_b/ϵ) v_b a_bᵀ / ‖v_b‖². This is unbiased for G: it is node perturbation with node noise
  induced by one shared weight probe.

### Optional corrections
- **Activation awareness (App. G):** use the clean-pass slope s = ρ'(h) and weight w = s². In node-space
  estimators, replace φ with φ⊙w before mapping to weights; keep the normaliser unweighted. In weight-space
  estimators, weight each per-sample loss difference per output row j by w_bj. ReLU gives a 0/1 mask. Do not
  apply it through normalisation layers or dropout. Gain: +1.4–2.5 points for 3–13% extra time.
- **Whitening (App. E):** Ĝ_white = (M_out+λI)^{-1} Ĝ (M_in+λI)^{-1}. Alternatively keep the bias as a
  preconditioner (Shampoo/SOAP/Muon).
- **Iterative vs simultaneous probing:** iterative perturbs one layer at a time and reruns from layer l onwards
  (cost ≈ F + n·L̄·F). Simultaneous perturbs all layers in one pass. Crosstalk adds variance
  Σ_{p≠l} ‖G_p‖²·S_l (Eq. 6) but cancels in expectation.

### Hyperparameters (Table A.6/A.7)
- B=128; 250 epochs; n=1 probe; Gaussian ϵ=1e-4; FP32 (TF32 off); SGD without momentum (Adam/SOAP in the
  appendix); constant LR; weight decay 0; label smoothing 0.1; leaky ReLU 0.01; no normalisation layers.
- **Adaptive clipping** (perturbation methods only): each tensor's norm is capped at 5× the lower median of
  its previous 100 norms, after 50 warm-up steps.
- Selected SGD LRs. MLP: NP/NTWP/SZO-1/SZO-∞ 1e-3, WP 1e-4, BP 1e-2. CNN: SZO-1 3e-3, SZO-∞ 3e-3,
  NTWP 1e-3, NP/WP 3e-4, BP 3e-2.
- With activation awareness the LRs are higher (SZO-1: 3e-2 MLP, 1e-2 CNN). Adam LRs are about 3e-5 to 3e-4.
- Credit: per-sample for NP/NTWP/SZO-1/SZO-∞; per-batch for WP.

## 4. Key results
- **Alignment (Fig. 1, App. J, random init, single layer perturbed):** SZO and NTWP angles are far below WP
  even with n ≪ parameter count. On conv layers NP aligns poorly under either kind of credit. Per-batch
  NTWP ≈ SZO-1, and per-sample NP = SZO-κ on linear layers, both as predicted. The κ sweep improves up to κ=1
  and saturates around κ≈2.
- **Final test accuracy, SGD, n=1:** BP reaches 89.9% (FMNIST) and 83.6% (CIFAR). On CIFAR, SZO-1 leads the
  ZO methods at about 46–47% validation. WP is at about 38%. Across settings SZO-1 beats WP by 3.5–15 points.
  On the MLP, NP = SZO-1 = SZO-∞ (about 86–87%).
- **More probes per step (fixed batch 128):** the SZO-1 vs NP gap on CIFAR grows from 6 to 10 points
  between n=1 and n=32. With awareness, NTWP rises from 48.2% to 64.5%.
- **Equal forward-pass budget:** more probes per step do *not* help, and every method falls for n≥8
  (SZO-1: 46.6% at n=1, 43.5% at n=8, 28.1% at n=32). Splitting a fixed per-step budget into more probes on a
  smaller batch *does* help: SZO-1 reaches 48.7% at (n=4, B=50) and 49.9% at (n=16, B=14) vs 45.7% at
  (n=1, B=128). Their rule: keep the step count, and spend per-step compute on a few probes over fewer examples.
- **Simultaneous probing on the CNN:** SZO-1 35% vs 46% iterative, SZO-∞ 33% vs 44%; NP stays at chance.
  The MLP is barely affected.
- **Cost (Table A.4, A100, B=128, n=1):** step time is 2.7–3.9× BP (SZO-1 3.9× on CIFAR). Peak memory is
  close to BP or lower (SZO-1 388 MiB vs BP 573 MiB on CIFAR).

## 5. Classification for Crowd v1.5
**Complement to DUST: an estimator upgrade inside the same forward-only pipeline.** It is not a new system.
- DUST is essentially NP with relative Gaussian noise on layer outputs. The paper predicts NP is *weak on
  shared-weight layers*. In a GPT every Linear is shared across T tokens, so it behaves like the paper's
  conv case. SZO-1, NTWP, and token-shared weight probes are the "realisable" alternative.
- **Main target:** low gradient cosine and high variance. Spectral shaping cuts the effective dimension to
  k·q_eff. Activation awareness (s² masking) is a near-free variance cut that DUST can adopt directly.
- **Secondary:** compute per useful step. Their result that a fixed budget is better spent on a few probes over
  a smaller batch than on more probes at a fixed batch, or on fewer steps, applies directly to DUST's choice of
  draws per batch.
- Partly addresses relative-σ instability: they use a tiny absolute ϵ=1e-4 in FP32 (linear regime) plus
  adaptive per-tensor median clipping. Both are cheap to try in DUST.
- Does not address communication, Byzantine peers, or async training. Uploads are still dense per-layer estimates.

## 6. MVP recipe (M5 Max, MPS, about 2–10 min)
Setup: a 7M GPT (vocab 4096, seq 128, d≈256, 4 layers) on real FineWeb-Edu tokens, FP32.

Minimal pieces:
1. **Per-layer hooks** on every nn.Linear: cache the clean input X (B×T×q), the clean output, and the GELU slope
   for fc1.
2. **Per-sequence loss vector** L_b (mean CE over the tokens of sequence b). Sequences are independent, so this
   is the clean "per-sample credit". Per-token credit is invalid under causal attention.
3. Estimators, each per layer, n probes, iterative mode (perturb one Linear, rerun only the downstream blocks):
   - (a) **DUST-like NP:** iid per-token node noise φ ~ N(0,σ²) on the output.
     Ĝ = Σ_b (ΔL_b/ϵ) Σ_t φ_{b,t} x_{b,t}ᵀ.
   - (b) **NTWP per-sample:** shared R ~ N(0,1) (k×q). ΔH_b = X_b Rᵀ, and
     Ĝ = (1/B) Σ_b k (ΔL_b/ϵ) ΔH_bᵀ X_b / ‖ΔH_b‖_F².
   - (c) **SZO-1 per-sample:** G_b ~ N(0,1/k) of shape k×T. ΔH_b = (X_b X_bᵀ) G_bᵀ / ‖X_b‖_F, and
     Ĝ = (1/B) Σ_b (ΔL_b/ϵ) G_b X_b / ‖X_b‖_F (einsum, nothing materialised).
   - (d) **WP baseline**, with per-batch credit.
   - (e) Activation-aware variants of (a) to (c), using w = GELU'(h)² on fc1.
4. **Diagnostic, about 2 min:** cosine(Ĝ, backprop G) per layer for n ∈ {1,4,16} at init and at an
   Adam-warmed checkpoint. Use 10 seeds and report mean ± sd.
5. **Training, about 5–8 min:** each estimator feeds SGD+momentum, which is DUST's outer optimizer, with ϵ=1e-4
   absolute and median-based clipping. Compare against Adam backprop and DUST. Plot val loss vs tokens, vs
   forward passes, and vs wall time. Also include simultaneous probing (one pass for all layers), because
   iterative probing costs about L× forwards.
6. Optional: a 4-worker simulation where each worker uses a different minibatch and the coordinator averages
   the estimates. This confirms the variance gain survives aggregation.

**Proves out if:** SZO-1/NTWP layer cosine is ≥1.5–2× DUST's at equal forward passes, and the val loss
vs wall-time curve beats DUST beyond seed noise. It is a bonus if s² awareness alone helps DUST.
Rule of thumb: at random init in their CNN, n=1 angles of about 70–80° became 40–60° with shaping.

## 7. Caveats / unclear points
- **There are no transformer or LLM experiments.** The largest model is a 6-layer CNN. LayerNorm, attention, and
  residual streams are untested; LayerNorm blocks activation awareness through it.
- All their headline training uses **iterative** probing (up to L× forward cost). Simultaneous probing, the
  regime closest to DUST's per-step cost, loses about 11 points on the CNN.
- Absolute performance is far below BP: 47% vs 83.6% on CIFAR after 250 epochs. This is an estimator-quality
  improvement, not BP parity.
- Normalisation constants differ between Alg. 1 (budget c), Alg. 2 (‖ΔH‖²), and per-sample NTWP (k/‖v‖²).
  The scale is effectively absorbed into the per-method tuned LR. The per-sample NTWP formula is given only for
  the vector (one patch) case; our token-matrix generalisation above is an extrapolation.
- κ>1 trains worse than κ=1 (κ=2 gave 43.4% vs 47.1%), but κ=2 used the LR tuned for κ=1.
- The isotropic-V prior is justified mainly at init. Mid-training gains may shrink as V becomes structured.
- Per-sample SZO-1 holds n·B per-example perturbations for one layer in memory (n·B·q·k entries) unless
  implemented implicitly, as we propose.
- Measured step times are research code on tiny nets, dominated by overheads; MAC counts are 1.3–2.5× BP.
- ϵ=1e-4 assumes FP32. On MPS, check that bf16/fp16 paths are not used for the loss differences.
